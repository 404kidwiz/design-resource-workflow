# 40 design resources — categorized catalog

Source: [Himanshu Hingorani's X post](https://x.com/himanshubuildss/status/2107877395348996471). Names and short descriptions follow the post, not an independent audit. A resource's inclusion does not imply an official skill, free access, live service, reusable license, or support in every agent. Open the actual site and verify terms before copying anything.

## Prompt packs and design systems (references, not installed packages)

1. [Scrolltide](https://scrolltide.co) — commercial-style complete site prompts and downloadable source; verify price/license before reuse.
2. [DesignMD](https://designmd.ai) — design-system text an agent may read when provided for a project.
3. [Vibe Prompts](https://vibeprompts.dev) — dashboard and landing-page prompts.

## Inspiration and UX patterns (web galleries)

4. [Minimal Gallery](https://minimal.gallery) — restrained sites.
5. [Kage](https://kage.design) — UI inspiration and prompts.
6. [Refero Styles](https://styles.refero.design) — product styles and typography.
7. [Component Gallery](https://component.gallery) — compare how design systems solve one UI element.
8. [Godly](https://godly.website) — website inspiration.
9. [Awwwards](https://www.awwwards.com) — recognized web design.
10. [Landing Love](https://www.landing.love) — animated sites.
11. [Land-book](https://land-book.com) — landing pages.
12. [Mobbin](https://mobbin.com) — mobile product patterns.
13. [Hover States](https://hoverstat.es) — experimental interactions.
14. [Navbar Gallery](https://navbar.gallery) — navigation patterns.
15. [Footer Design](https://footer.design) — footer layouts.
16. [CTA Gallery](https://cta.gallery) — conversion UI examples; do not treat third-party claims as verified conversion evidence.
17. [Supahero](https://supahero.io) — hero sections.
18. [Pricing Pages](https://pricingpages.design) — pricing-page references; preserve actual product and billing facts.

## Components and visual effects (choose per project; never globally install into every repo)

19. [21st.dev](https://21st.dev) — React component marketplace and optional authenticated MCP/CLI; verify live setup and account before connecting.

## Builders and editors (separate products, not skills to install in another tool)

37. [Claude Code](https://www.claude.com/product/claude-code) — AI coding agent; use an installed/authenticated CLI when available.
38. [Cursor](https://cursor.com) — AI code editor; use an installed/authenticated editor when available.

40. [Lovable](https://lovable.dev) — hosted app builder; project export requires an explicit task.

### Example routes

- Dashboard navigation → compare 7, 12 and 14; then implement with the current project's accessible primitives.
- Landing-page direction → inspect 4, 9, 11 and 17; choose two contrasting examples, not a clone.
- React interaction → inspect 19–25; prefer the project's existing component and animation stack first.
- Motion/3D → consult 10, 27, 30–34; provide reduced-motion fallback and measure bundle/render cost.
- AI-generated prototype → use 2–3 or 37–40 only with authorized account/code-sharing and real product facts.
